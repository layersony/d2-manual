Controller area network (can) outline

• ABS HU/CM transmit/received the information through the CAN. For detailed information of the CAN, see the "CONTROLLER AREA NETWORK (CAN) SYSTEM OUTLINE." (See CONTROLLER AREA NETWORK (CAN) SYSTEM OUTLINE.)

Transmitted Information

• Wheel Speed
- Front left
- Front right
- Rear left
- Rear right
• Brake system status
• Brake system configuration (EBD/ABS)

Received Information

• Transmission/axle type from PCM
• Tire circumference from PCM
