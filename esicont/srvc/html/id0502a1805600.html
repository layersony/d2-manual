PID/data monitor inspection [FN4A-EL]

1. Connect the WDS or equivalent to the DLC-2.

2. Measure the PID value.

Note
• Perform part inspection for the output device after PCM inspection.
• The PID/DATA MONITOR function monitors the calculated value of the input/output signals in the PCM. Therefore, if a monitored value of an output device is out of specification, it is necessary to inspect the monitored value of the input device related to the output device control. Since an output device malfunction is not directly indicated as a malfunction of the monitored value for the output device, it is necessary to inspect the output device individually using methods such as the simulation function.
