DTC B2477

Note
• DTC B2477 cannot be cleared by performing the "Clearing DTCs Procedure." It will be cleared when the configuration procedure is performed properly.

DTC

B2477

EPS CM configuration

DETECTION CONDITION

• Configuration write failure is detected.

POSSIBLE CAUSE

• Module configuration procedure has not been performed properly.

Diagnostic procedure

STEP

INSPECTION

ACTION

1
CONFIGURE THE EPS CM USING WDS OR EQUIVALENT
• Configure the EPS CM using the WDS or equivalent.
(See EPS CONTROL MODULE CONFIGURATION.)
After the configuration is completed, go to the next step.
2
VERIFY TROUBLESHOOTING COMPLETED
• Is the same DTC present?
Yes
• Return to Step 1.
• If the malfunction recurs, replace and configure the EPS CM, then go to the next step. (See EPS CONTROL MODULE REMOVAL/INSTALLATION.) (See EPS CONTROL MODULE CONFIGURATION.)
No
Go to the next step.
3
VERIFY AFTER REPAIR PROCEDURE
• Clear the DTC from the memory.
(See Clearing DTCs Procedure.)
• Are there any other DTCs present?
Yes
Go to the applicable DTC inspection. (See DTC Table.)
No
DTC troubleshooting completed.
