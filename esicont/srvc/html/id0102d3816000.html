OBD on-board system readiness test [ZY]

• This shows the OBD systems operating status. If any monitor function is incomplete, WDS or equivalent will identify which monitor function has not been completed. The fuel system, misfire and CCM are continuous monitoring-type functions. The HO2S and catalyst will be monitored under drive cycles. The OBD diagnostic system is initialized by performing the DTC cancellation procedure or disconnecting the negative battery cable.
