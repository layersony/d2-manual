Brake features

Improved Braking Stability
• Large diameter front disc plate has been adopted
• Wide width lining for the rear brake drum has been adopted
• Large diameter power brake unit has been adopted
Improved Safety
• Intrusion-minimizing brake pedal has been adopted
• Mechanical brake assist has been adopted (With ABS)
Improved reliability
• ABS wheel-speed sensor with a semiconductor element has been adopted
• ABS sensor rotor with a magnetic encoder has been adopted
Improved Serviceability
• Controller area network (CAN) communication function has been adopted
• Data link connector-2 (DLC-2) has been adopted
• Using the WDS or equivalent with the ABS HU/CM allows for a 4-digit DTC display function, a PID/DATA monitor function, and an active command modes function
Improved brake pedal operability
• Tandem type master cylinder adopted
