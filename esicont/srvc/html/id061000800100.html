General procedures (steering)

Wheel And Tire Installation

1. When installing the wheels and tires, tighten the wheel nuts in a criss-cross pattern to the following tightening torque.

Tightening torque
88.2-117.6 N·m
{9.00-11.99 kgf·m, 65.06-86.73 ft·lbf}

Connectors Disconnection

1. Disconnect the negative battery cable before performing any work that requires handling of connectors. (See BATTERY REMOVAL/INSTALLATION [ZY].)

Suspension Links Removal/installation

Note
• To prevent the bushings from being twisted or pinched, perform the procedures with no passengers or luggage aboard the vehicle.

1. For the joint section with rubber bushings, raise the vehicle using a lift, and then temporarily tighten the installation bolts and nuts. After the vehicle has been lowered to the ground, tighten them to the specified torque.

EPS Related Parts

1. Make sure that there are no DTCs in the EPS memory after working on EPS related parts. If there are any codes in the memory, clear them.

EPS System Configuration

Warning
• If the configuration procedure is not completed, the EPS will not operate properly and it might cause an unexpected accident. Therefore, when replacing or removing the EPS CM, make sure to perform the configuration procedure to ensure proper EPS operation.

1. When replacing the EPS CM, perform the configuration procedure. (See EPS CONTROL MODULE CONFIGURATION.)
