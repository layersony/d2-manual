Outline

• The OBD (on-board diagnostic) system has the following function:
- Malfunction detection: Detects malfunctions in the air bag system and outputs DTCs.
- Data monitor function: Reads out specific input/output signals and the system status.
• Diagnostic DTCs can be read/cleared using the WDS or equivalent.
