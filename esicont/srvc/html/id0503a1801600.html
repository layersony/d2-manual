No.11 shift point is high or low [FN4A-EL]

11

Shift point is high or low

DESCRIPTION

• Shift point considerably different from automatic shift diagram.
• Shift delays when accelerating.
• Shift occurs quickly when accelerating and engine speed does not increase.

POSSIBLE CAUSE

• If the transaxle does not shift abnormally, there is a malfunction of the input signal to the accelerator pedal position sensor, TP sensor, input/turbine speed sensor, or vehicle speed sensor (including sensor GND).
• If the engine speed is high or low, regardless normal shifting, inspect the tachometer.
• Verify that the output signal of the accelerator pedal position sensor, TP sensor changes linearly.
