No.13 no kickdown [FN4A-EL]

13

No kickdown

DESCRIPTION

• Does not downshift when accelerator pedal is fully depressed within kickdown range.

POSSIBLE CAUSE

• If transaxle does not downshift though shifting is normal, malfunction is in accelerator pedal position sensor, TP sensor circuit (including sensor GND, sensor harness and connector).
