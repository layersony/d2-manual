Instrument cluster removal/installation

Caution
• When replacing the instrument cluster, the configuration procedure must be performed before removing the instrument cluster. If the configuration procedure is not performed before removing the instrument cluster, it is possible that the instrument cluster will not operate normally.

1. Configure the instrument cluster (when only replacing it). (See INSTRUMENT CLUSTER CONFIGURATION.)

2. Disconnect the negative battery cable.

3. Pull down the adjusting lever of the tilt steering wheel and push the steering wheel down.

4. Remove the meter hood. (See METER HOOD REMOVAL/INSTALLATION.)

5. Remove in the order indicated in the table.

1
Screw
2
Connector
3
Instrument cluster
(See Instrument Cluster Removal Note)

6. Install in the reverse order of removal.

Instrument Cluster Removal Note

1. When removing the instrument cluster, cover the steering shaft with a cloth to prevent damage to the lens.
