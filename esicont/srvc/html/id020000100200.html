Suspension features

Improved rigidity
• Strut type front suspension with an L-shaped lower arm adopted
• Large-sized rubber mount for the lower arm adopted
• Large-sized, flat surface type front crossmember adopted
• Torsion beam axle system adopted for the rear suspension
Improved riding comfort and handling stability
• Separate input type shock absorber mount adopted
• Large-sized rubber bushing adopted for the torsion beam
Reduced vibration and weight
• Aluminum front lower arm bushing bracket (rear) adopted
Improved handling stability
• Mono-tube type shock absorber adopted
• lightweight aluminum wheel adopted
Increased cabin space
• Separated positioning of the shock absorber and coil spring adopted
