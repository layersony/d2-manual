DTC 09: ER22

DTC 09: Er22

Base unit (peripheral circuit)

DETECTION CONDITION

• Base unit detects malfunction in its internal circuit (related to tuner).

POSSIBLE CAUSE

• Base unit malfunction

Diagnostic procedure

Step

Inspection

Action

-
INSPECT BASE UNIT
• Clear DTC.
• Turn on radio and operate it for 3 s or more.
• Start on-board diagnostic test mode.
• Is DTC 09: Er22 displayed?
Yes
Replace base unit.
No
Troubleshooting completed.
