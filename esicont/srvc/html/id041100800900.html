Disc Plate Removal Note

1.  Mark the wheel hub and disc plate.

ada6912w018

2.  Remove the disc plate.


Disc Plate Installation Note

1.  Remove any rust or grime on the contact face of the disc plate and wheel hub.

2.  Align the marks made before removal and install the disc plate to the wheel hub.


Disc Pad Installation Note

1.  Clean the outside of the piston.

2.  Push the piston in using the SST.

adj6912w023

3.  Install the disc pads.


Retaining Clip Installation Note

Warning
•  Never use a tool when installing the retaining clip as it could cause serious injury if excessive force is applied while doing the work. Install the retaining clip using the following procedure:

1.  Temporarily install the retaining clips to the three positions on the caliper and the mounting support shown in the figure using the following procedure: (Insert the retaining clip to caliper hole A, but not to hole B.)

hda411zw1s01

(1)  Insert the retaining clip to caliper hole A.
(2)  Install the retaining clip to the underside of the mounting support.
(3)  Install the retaining clip to the upper side of the mounting support.

2.  Hold the retaining clip so that it does not detach from the caliper and the mounting support.

3.  While holding the retaining clip, press area C shown in the figure in the direction of the arrow, bend the retaining clip, and insert area B to the caliper hole.

hda411zw1s02

4.  Verify that the retaining clip is securely installed to the caliper and the mounting support.


Brake Hose Installation Note

1.  Install the brake hose to the caliper.

2.  Tighten the flare nut while holding the brake hose at point A with a spanner or equivalent.

b3e0411w043

3.  Verify that the brake hose is not twisted.
