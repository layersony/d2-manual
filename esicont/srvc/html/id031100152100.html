Wheel Hub Component Disassembly Note

1.  Remove the wheel hub component using the SSTs.

am2zzw00007085

2.   If the bearing inner race remains on the front wheel hub component, grind a section of the bearing inner race until approx. 0.5 mm {0.02 in} remains.

am2zzw00007086

3.  Remove the bearing inner race using a chisel.


Wheel Bearing Disassembly Note

1.  Remove the wheel bearing from the steering knuckle using the SSTs.

am2zzw00007087


Wheel Hub Bolt Disassembly Note

Note
•  The hub bolts do not need to be removed unless they are being replaced.

1.  Remove the wheel hub bolts from the wheel hub using a press.

am2zzw00007088


Wheel Hub Bolt Assembly Note

1.  Install new wheel hub bolts using a press.

am2zzw00007089


Wheel Bearing Assembly Note

1.  Install a new wheel bearing using the SSTs.

am2zzw00007090

Caution
•  For vehicles with ABS, install the bearing to the steering knuckle so that the magnetic rubber side (dark brown color) faces toward the inside of the vehicle.
•  For vehicles without ABS, the bearing can be installed in either direction.


Wheel Hub Component Assembly Note

1.  Install the wheel hub component using the SSTs.
