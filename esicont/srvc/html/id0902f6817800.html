DTC 06: ER07

DTC 06: Er07

CD changer (upper module)

DETECTION CONDITION

Note
• When error occurs, error message "CHECK CD" is displayed in the LCD.
• Base unit detects CD reading error.

POSSIBLE CAUSE

• Defective CD (scratches or dirt)
• CD changer (upper module) malfunction

Diagnostic procedure

Step

Inspection

Action

1
VERIFY WHETHER MALFUNCTION IS IN CD CHANGER (UPPER MODULE) OR CD
• Play all CDs in changer.
• Is CD changer able to read them properly?
Yes
Go to Step 3.
No
Not able to read particular CD.
Go to the next step.
Not able to read any CD.
Go to Step 3.
2
INSPECT CD
• Inspect condition of CD where error has occurred.
• Is CD okay?
Yes
Go to the next step.
No
Repair (remove foreign material) or replace CD, then go to the next step.
3
INSPECT CD CHANGER (UPPER MODULE)
• Clear DTC.
• Insert and play CD for 12 s or more.
• Start on-board diagnostic test mode.
• Is DTC 06: Er07 displayed?
Yes
Replace CD changer (upper module).
No
Troubleshooting completed.
