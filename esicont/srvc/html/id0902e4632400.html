Security light: DTC 13 (WDS: DTC B2431)

DTC 13 (B2431)

ID number programing failure.

POSSIBLE CAUSE

• The procedure fails to program the transponder into PCM

Diagnostic procedure

Step

Inspection

Action

1
VERIFY DTC USING SST
• Does WDS indicate DTC B2431?
Yes
Go to Step 3.
No
Go to the next step.
2
VERIFY DTC USING SST
• Does WDS indicate DTC B1600?
Yes
Go to SECURITY LIGHT: DTC 13 (WDS: B1600).
No
Go to the next step.
3
INSPECT PCM
• Erase key ID number using WDS and register key ID number.
(See IMMOBILIZER SYSTEM COMPONENT REPLACEMENT/KEY ADDITION AND CLEARING.)
• Using registered key, turn the ignition switch to the ON position.
• Does WDS indicate DTC B2431 again?
Yes
Replace PCM and reprogram immobilizer system.
(See IMMOBILIZER SYSTEM COMPONENT REPLACEMENT/KEY ADDITION AND CLEARING.)
No
Troubleshooting is completed.
