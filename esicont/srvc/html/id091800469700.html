Light switch removal/installation

1. Disconnect the negative battery cable.

2. Remove the column cover.

3. Remove in the order indicated in the table.

1
Connector
(See Connector Installation Note.)
2
Light switch
(See Light Switch Installation Note.)

4. Install in the reverse order of removal.

Connector Installation Note

1. Insert the light switch wiring harness shown in the figure into the clock spring hook.

Light Switch Installation Note

1. Set the light switch groove and hook at the positions indicated in the figure, and insert them into the body.

2. Insert the light switch until the light switch tab is engaged with the body.
