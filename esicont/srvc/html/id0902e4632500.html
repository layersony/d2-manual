Security light: DTC 14 (WDS: DTC B1602)

DTC 14 (B1602)

PCM received invalid format of ID number from key (transponder)

POSSIBLE CAUSE

• Defective transponder in the key
• Defective coil
• Defective PCM

Diagnostic procedure

Step

Inspection

Action

1
INSPECT FOR OTHER PROPER KEYS
• Using any other valid key, turn the ignition switch to the ON position.
• If there are no other valid keys, then register an additional key using WDS and turn the ignition switch to the ON position.
(See IMMOBILIZER SYSTEM COMPONENT REPLACEMENT/KEY ADDITION AND CLEARING.)
• Does security light or WDS indicate DTC 14 (B1602) again?
Yes
Replace coil, then go to the next step.
(See COIL REMOVAL/INSTALLATION.)
No
• Dispose of defective key.
• Duplicate key if necessary.
(See IMMOBILIZER SYSTEM COMPONENT REPLACEMENT/KEY ADDITION AND CLEARING.)
2
INSPECT PCM
• Turn the ignition switch to the ON position with the registered key.
• Does security light or WDS indicate DTC 14 (B1602) again?
Yes
Replace PCM and reprogram immobilizer system.
(See IMMOBILIZER SYSTEM COMPONENT REPLACEMENT/KEY ADDITION AND CLEARING.)
No
Troubleshooting is completed.
