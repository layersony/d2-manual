Clutch outline of construction

• The hydraulic control type clutch control system consists of the following parts.
- Brake and clutch fluid reservoir tank
- Clutch master cylinder
- Clutch release cylinder
- Clutch release fork
- Clutch release collar
- Clutch cover
- Clutch disc
- Flywheel
