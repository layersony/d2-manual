Shift solenoid A, B and C (duty-cycle type) outline [FN4A-EL]

• A clutch pressure direct control, which supplies the clutch pressure directly to each clutch and/or brake, has been adopted. A three-way duty-cycle type solenoids with excellent controllability have been adopted, to improve response.
