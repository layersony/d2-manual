Memory function [FN4A-EL]

• The memory function stores malfunction information detected in the malfunction detection function. Once malfunction information is stored, the memory will not be cleared even when the ignition switch is turned off (LOCK position) or the malfunction is repaired.
• The stored memory (malfunction information) can be cleared using the WDS or equivalent, or by disconnecting the negative battery cable.
