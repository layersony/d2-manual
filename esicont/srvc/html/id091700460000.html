Rear door trim removal/installation

1. Disconnect the negative battery cable.

2. Open the cap using a small flathead screwdriver, then remove screw A.

3. Remove the inner handle cover.

4. Remove the recess cover on vehicles with a recess cover.

5. Remove screw B.

6. Disengage clips A from the body using a fastener remover.

7. Pull the rear door trim upward, then disengage clips B from the rear door trim.

8. Disconnect the power window subswitch connector.

9. Remove clips B from the body using a fastener remover, then install them to the rear door trim.

10. Install in the reverse order of removal.
