Secondary gear bearing preload

Note
•  For the secondary gear and output gear bearing preload, measure the bearing preload with the primary gear and the secondary gear and output gear assembled to the transaxle case because it cannot be measured with the secondary gear and output gear as a single unit.

1.  Assemble the primary gear. (See AUTOMATIC TRANSAXLE ASSEMBLY.)

Note
•  Record the primary gear bearing preload value measured in Step 2, as it is necessary for the adjustment of the secondary gear and output gear bearing preload adjustment.

2.  Measure the primary gear bearing preload.

baf4za00000062

•  If not within the specification, newly replace the locknut and collapsible spacer, and readjust the preload. (See AUTOMATIC TRANSAXLE ASSEMBLY.)
Primary gear bearing preload
0.5—0.9 N·m {5.1—9.1 kgf·cm, 4.5—7.9 in·lbf}

3.  Remove the bearing race and adjustment shim from the converter housing using the SST.

baf4za00000115

4.  Install the funnel and bearing race to the transaxle case.

baf4za00000116

5.  Install the the secondary gear and output gear to the transaxle case.

6.  Install the bearing race removed in Step 3 to the secondary gear and output gear.

baf4za00000117

7.  Set the SSTs on to the primary gear and the secondary gear and output gear.

baf4za00000118

8.  Rotate parts A and B of the SST and eliminate the gap indicated by the arrow in the figure.

baf4za00000119

9.  Install the SSTs (6 collars) in the positions shown in the figure.

baf4za00000120

10.  Set the converter housing on the transaxle case and tighten it using the SSTs (bolts).

baf4za00000121

Tightening torque
19—25 N·m {1.9—2.6 kgf·m, 14—18 ft·lbf}

11.  To allow the bearing to drop, widen the gap shown in the figure by rotating the SST (selector) until it no longer moves using the SSTs (bars).

baf4za00000122

12.  Rotate the SST (selector) back and reduce the gap.

13.  Insert the extension bar from the converter housing and install it to the SST (preload adapter).

14.  Using the following formula, calculate the secondary gear and output gear bearing load adjustment value.

Secondary gear and output gear bearing preload adjustment
Primary gear bearing preload (value calculated in Step 2) + 0.675 N·m {6.9 kgf·cm, 6.0 in·lbf}
Note
•  Measure the preload value when the primary gear was first rotated.

15.  Adjust the SST (selector) clearance using the SSTs (bars) so that it is the preload adjustment is the value calculated in Step 14.

baf4za00000123
baf4za00000122

Note
•  Measure with the gap of the SST (shim selector) spanning the entire circumference.

16.  Measure the gap indicated by the arrow in the figure.

baf4za00000124

Note
•  The number of adjustment shims used is one or less.

17.  Select an adjustment shim which matches the gap measured in Step 16.

18.  Remove the SSTs and the converter housing.

19.  Assemble the selected adjustment shim and bearing race to the converter housing.

baf4za00000125

20.  Assemble the converter housing to the transaxle case.

Tightening torque
19—25 N·m {1.9—2.6 kgf·m, 14—18 ft·lbf}

21.  Set the SST (preload adapter) on to the primary gear.

22.  Insert the extension bar from the converter housing and install it to the SST (preload adapter).

23.  Verify that the secondary gear and output gear bearing preload adjustment value is within the specification.

Secondary gear and output gear bearing preload adjustment
Preload adjustment value calculated in Step 14 ± 0.275 N·m {2.9 kgf·cm, 25 in·lbf}

24.  If not within the specification, repeat from Step 1.

25.  Remove the converter housing.
